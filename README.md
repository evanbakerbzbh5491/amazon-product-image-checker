## What Amazon Image Checker Does

Amazon Image Checker gives reviewers and product teams a practical way to inspect the primary image attached to an Amazon listing. It combines automated pixel-based checks with optional reviewer input so image compliance can be assessed through a structured browser workflow.

All image inspection is handled locally through browser canvas functionality. The application does not depend on a backend or API, and after the first load it can be used offline for workflows that favor client-side processing.

- Reviews Amazon main product images for compliance-related indicators

## Frequently Asked Questions

### Is an API required?

No. Amazon Image Checker performs its analysis locally and does not require a backend or API.

### Will the tool run offline?

Yes. Offline use is supported once the application has completed its initial load.

### Which images can be reviewed?

The checker is intended for Amazon main product images. It evaluates them with automated pixel analysis and can also include manual reviewer confirmation.

No. Automated analysis is paired with optional manual confirmations. Use the results from both parts of the workflow when reviewing an image.

Image processing occurs on the client side in the browser through canvas-based inspection.
